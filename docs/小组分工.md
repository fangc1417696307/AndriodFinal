# Mogu 蘑菇识别 Android App · 小组分工（必须完成项）

> 项目范围：用户端 7 个模块，不做管理端。
> 技术栈：Kotlin + XML View + Room + Retrofit/OkHttp + Coroutines + Material 3。
> 计划周期：约 2–3 周。
> 当前基础：可运行骨架已完成，包含登录、图鉴、本地菌讯、识别（本地 Mock 兜底）、记录、反馈、设置等页面。

## 三、每个人的详细任务

### 成员 A（组长）

1. **DeepSeek 配置页**
   - 在“我的 → 识别设置”增加“测试连接”按钮。
   - 用一个最小请求验证 key 是否可用，成功/失败都要有明确提示。
   - key 只保存在本机 SharedPreferences，不得写进源码、`strings.xml` 或提交到 Git。
2. **登录/注册/个人中心回归**
   - 注册：仅需用户名 3–20 位、密码 6–32 位、两次密码一致；姓名默认为用户名，之后可在个人中心修改。
   - 登录：错误密码提示；登录后重启 App 仍保持登录。
   - 改密：原密码错误提示；改密后能用新密码登录。
   - 退出：清除会话并回到登录页。
3. **展示与文档**
   - 换应用图标，加简单启动页（可选）。
   - 写 `README.md`：环境要求、运行方式、演示账号 `demo / 123456`、DeepSeek Key 配置、模块分工。
   - 写一页演示脚本，按“登录 → 图鉴 → 本地 → 识别 → 记录 → 反馈 → 个人中心”的顺序。
4. **集成与交付**
   - 负责 `main` 分支合并顺序和冲突处理。
   - 每次合并后跑一次 `./gradlew clean :app:assembleDebug`。
   - 打 tag、出 APK、录制/整理演示视频。

### 成员 B（识别与记录）

1. **相机/相册**
   - 相机权限、FileProvider、拍照后图片旋转/压缩。
   - 相册使用系统 Photo Picker，兼容 Android 13/14。
   - 读取失败、权限拒绝要有提示，不能崩溃。
2. **在线识别**
   - 真实 DeepSeek key 下测试 `deepseek-flash`。
   - 处理 401（key 错）、429（限流）、超时、无网络。
   - 失败自动切本地 Mock，并在结果页标明来源。
   - prompt 只允许从内置 40 种里选，要求输出 JSON；解析失败走兜底。
3. **记录列表**
   - 关键词搜索（名称/别名）。
   - 可食用/有毒筛选。
   - 仅看收藏。
   - 按识别时间倒序；空态、加载态正常。
4. **记录详情**
   - 图片点击预览。
   - 审核状态说明：没有管理端时不要显示容易误解的“审核中”，建议显示“本地记录”或“待审核（本地）”。
   - 收藏、删除、反馈入口全部可用。
5. **结果页**
   - Top3、置信度、来源、风险提示。
   - 点击候选跳图鉴详情。
   - 识别完成写入 Room，记录页能立即看到。

### 成员 C（图鉴与本地）

1. **图鉴列表**
   - 分类筛选（`CategoryEntity` 已导入）。
   - 最新/热门排序（`viewCount`）。
   - 搜索 + 类型筛选 + 分类筛选可组合。
   - 空态、加载态正常。
2. **图鉴详情**
   - 相关推荐（`MushroomRepository.getRelated`）。
   - 有毒品种醒目提示。
   - 分类、季节、形态、分布、毒性、食用建议、补充说明完整展示。
   - 封面缺失时使用统一占位图。
3. **本地菌讯**
   - 省份 + 城市选择（`RegionEntity.citiesJson` 已有城市数据）。
   - 显示“省/市 · 大区”。
   - 可食用/有毒两组分别展示；空分区隐藏。
   - 显示每组数量；地区选择持久化。
4. **搜索历史**
   - 使用 `SearchHistoryDao` 展示最近搜索。
   - 点击回填搜索框，支持清空。

## 四、协作与合并规则

1. 所有开发从最新 `main` 切分支，不直接改 `main`。
2. 每人按小功能拆 PR，不要憋到最后一次性合并。
3. 公共文件由 A 统一改：`AndroidManifest.xml`、`build.gradle.kts`、`libs.versions.toml`、`themes.xml`、`colors.xml`、`MainActivity`、`menu_bottom_nav.xml`。
4. 资源按模块拆文件：`strings_auth.xml`、`strings_identify.xml`、`strings_records.xml`、`strings_wiki.xml`、`strings_local.xml`、`strings_profile.xml`、`strings_feedback.xml`、`strings_settings.xml`。
5. 每个人只改自己的包：
   - A：`ui/auth`、`ui/profile`、`ui/feedback`、`ui/settings`、基础 `data`/`util`
   - B：`ui/identify`、`ui/records`、`data/repository/IdentifyRepository`、`MockIdentifyEngine`
   - C：`ui/wiki`、`ui/local`、`data/repository/MushroomRepository`
6. 合并前先同步：
   ```bash
   git fetch origin
   git merge origin/main
   ```
7. PR 完成定义：
   - 本地 `./gradlew :app:assembleDebug` 通过
   - 真机/模拟器自测主流程
   - PR 描述包含功能、测试步骤、截图
   - 没有提交 `local.properties`、`.idea/`、签名文件、API Key
8. 提交信息格式：
   - `feat(identify): ...`
   - `feat(records): ...`
   - `feat(wiki): ...`
   - `fix(local): ...`
